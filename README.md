#Capital Shop
Capital Shop is a modern fashion e-commerce website built using HTML5 and CSS3. It focuses on creating a visually engaging shopping experience with a multi-section layout, smooth animations, and interactive UI components inspired by real-world online stores.
  
🛍️ Product Showcase  
- Multi-section layout for Men, Women, and Baby collections  
- Featured products with pricing and hover effects  
- Trending and recommended product sections  

🎨 Interactive UI  
- Rotating product cards with front/back image transitions  
- Fade-in and hover animations for smooth user interaction  
- Floating action buttons (cart, wishlist, search)  
- Dropdown navigation menu with multi-column layout  

📰 Content Sections  
- Customer testimonial section  
- Latest fashion news/blog section  
- Promotional banners and hero section  

📱 User Experience  
- Responsive layout using modern CSS techniques  
- Smooth transitions and visual effects for better engagement  
- Clean and structured UI inspired by real e-commerce platforms  

🛠️ Tech Stack  

Frontend  
- HTML5  
- CSS3  
- Flexbox & Grid Layout  
- CSS Animations & Keyframes  
- CSS Transforms & Transitions  
- Font Awesome Icons & Google Fonts  

🎯 Purpose  
This project was built to strengthen front-end development skills, focusing on layout design, CSS animations, and building interactive and visually appealing user interfaces without JavaScript.
